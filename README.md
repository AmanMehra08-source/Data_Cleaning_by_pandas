# Data_Cleaning_by_pandas

###  

This Excel file contains **8,790 records and 9 columns** related to movies/TV shows. The dataset includes information such as **Show ID, Type, Title, Director, Country, Date Added, Release Year, Duration, and Genre**.

### Data Cleaning using Pandas

The dataset was cleaned using **Python Pandas**. The main cleaning steps include:

* Checked the dataset structure, columns, and data types.
* Identified and handled **missing values** in important columns.
* Removed **duplicate records** where applicable.
* Standardized text values such as **Type, Country, and categorical fields**.
* Cleaned unnecessary spaces and inconsistent text formatting.
* Converted **Date Added** into a proper date format.
* Checked numeric columns such as **Release Year** for valid values.
* Cleaned and standardized the **Duration** column.
* Verified the final dataset for consistency and usability.

**Tools used:** Python, Pandas, Jupyter Notebook and Excel.

**Result:** A cleaner and more consistent dataset that is ready for **data cleaning **.
